# Physiotherapy Clinic Scheduler

This is a simple web application built to simulate a real physiotherapy clinic scheduling system.

## Features
- Weekly schedule (Monday - Sunday)
- Hourly appointment tracking (09:00 - 18:00)
- Patient name and notes
- Local data storage

## About
I am a physiotherapist transitioning into software development. 
This project reflects my interest in combining healthcare knowledge with digital solutions.
